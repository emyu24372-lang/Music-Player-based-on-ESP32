This project includes the electrical schematic,
the enclosure files, and the code for the ESP32. 
To run the code, you need to install some specific libraries for the ESP32 board.
The code was not written by me, but the enclosure and the electrical schematic were designed by me.
In the electrical schematic, you can see where all the connections go.
You just need to follow the labels on the pins.
